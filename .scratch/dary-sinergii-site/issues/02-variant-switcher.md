# 02 — Переключатель четырёх вариантов

**What to build:** A presentation switcher that applies one of four complete site variants across every route, persists through navigation, supports direct links, and can later be disabled without deleting the variant code.

**Blocked by:** 01 — Статическая основа и единый контент

**Status:** done

- [x] Four named variants are selectable on every route.
- [x] URL state overrides stored state, and the active choice persists during navigation.
- [x] The switcher is keyboard accessible, labelled, responsive, and removable through configuration.
- [x] Shared content remains identical across variants.
