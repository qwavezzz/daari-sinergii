## Responsive and accessibility constraints

- Desktop comp reference is `1536 × 1024`; preserve its dominant media scale and compact `~78vh` hero, but let the live layout, not a background bitmap, determine geometry.
- Hero media remains `16:9`; product/category visual slots use stable square or `4:3` boxes so placeholders and later photography swap without layout shift.
- Inline SVGs must use `currentColor`, a viewBox, and non-scaling strokes where appropriate. Decorative SVG/Canvas layers are `aria-hidden`; informative media receives real captions/alt text derived from verified content.
- The procedural field must use a deterministic static frame for `prefers-reduced-motion`, pause when offscreen/hidden, reduce particle density on mobile, and cap device pixel ratio.
- Core offer, navigation, direction titles, descriptions, and actions must remain visible with video, Canvas, CSS images, or JavaScript disabled.
- Do not use remote stock URLs, external embeds, base64-embedded mock crops, screenshots of text, raster UI chrome, or generated images presented as company evidence.
