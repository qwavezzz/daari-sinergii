# ПВЗ СДЭК на OpenStreetMap

Status: done

Покупатель выбирает доступный ПВЗ СДЭК в России на постоянно видимой карте OpenStreetMap или в синхронизированном списке. Дизайн наследует существующее оформление магазина. Карта работает без ключа Яндекса; Leaflet и Supercluster поставляются в сборке сайта.

Подтверждено пользователем: только ПВЗ, Россия, геолокация с разрешения покупателя. Сейчас доступны только тестовые ключи СДЭК. Режим API явно указан; боевые сроки, цены и доступность проверяются после получения рабочих ключей.

Геолокация вызывается по кнопке «Рядом со мной» и перемещает карту без обращения к геокодеру. При отказе/ошибке остаются поиск по городу/адресу и перемещение карты. Пункты, адреса, часы работы и координаты приходят из API СДЭК. На карте нет вымышленных пунктов в рабочем режиме. Выбор передаёт серверу только скрытый код ПВЗ; проверка пункта, упаковок, суммы и подписанного расчёта сохраняется.

Карта видна сразу при выборе доставки СДЭК и после выбора ПВЗ; кнопок показа/скрытия и ручного ввода кода нет. Справочник автоматически загружается страницами по 500. Близкие точки группируются с количеством, нажатие раскрывает следующий уровень точности; совпадающие координаты на предельном масштабе показывают список адресов в карточке. Атрибуция OpenStreetMap видна; тайлы загружаются только для текущего просмотра, без предзагрузки городов. Ошибка карты не блокирует список и оформление. Координаты покупателя используются только в памяти браузера и не отправляются серверу приложения/СДЭК.

Приёмка: карта/список на desktop и mobile, геолокация и отказ, тайм-аут API/карты, смена города/пункта и устаревшие ответы, серверная проверка цены, сохранение контактов, клавиатурный выбор, CSP, тесты и сборка.

2026-10-01: пользователь уточнил постоянную видимость карты и кластеризацию по примеру Wildberries. Устранена причина таймаутов — заголовок Connection: close у старого HTTP-клиента. На локальном сервере проверены загрузка 1280 ПВЗ России, поиск 8 ПВЗ Тольятти, раскрытие кластеров и расчёт 156 ₽ для учебной посылки на desktop/mobile. Боевой запуск требует рабочих ключей.
