# Постоянная карта с реальными ПВЗ и кластерами

Status: done

Запрос пользователя: убрать ручной код, убрать показ/скрытие карты, загружать реальные точки сразу, группировать точки и раскрывать их при увеличении масштаба, как в примере Wildberries.

Реализовано: автоматическая загрузка российского справочника страницами по 500, локальный поиск города/адреса, синхронизация списка с областью карты, Supercluster с центрами групп и количеством, карточки ПВЗ, геолокация без зависимости от API определения города. Код ПВЗ скрыт и устанавливается только выбором. Карта остаётся после расчёта. Повтор загрузки данных/тайлов и серверного расчёта сохранён.

Исправлена причина прежних таймаутов: urllib добавлял Connection: close, на который шлюз СДЭК не отвечал. HTTPSConnection использует обычный HTTP/1.1 без этого заголовка, не следует перенаправлениям и ограничивает ответ 8 МБ. Добавлены регрессионные проверки.

Проверено на реальной локальной базе: 1280 ПВЗ из sandbox, 8 в Тольятти, группировка и выбор на desktop/mobile, ответ калькулятора 156 ₽ для учебной посылки, заказ не отправлялся. Скриншоты: var/artifacts/cdek-always-map/.

Автотесты: 20 сценариев Chromium (11 СДЭК, 7 магазина, 2 пробной оплаты); полный набор Django — 213 тестов (1 skip), включая 84 теста заказов. Сборка, ruff, check:js прошли.

Независимая проверка интерфейса: ship. Единственное замечание — устаревшее описание карты — исправлено в templates/shop/DESIGN.md и sidecar; повторная проверка подтвердила устранение. Открытых замечаний нет.
