# 01 — Оплата заказа через Альфа-Банк

Status: done
Blocked by: None

**What to build:** Полная замена платёжного адаптера на прямой REST API Альфа-Банка с оплатой сохранённого итога заказа, безопасными повторами, проверкой статуса и учётом возвратов.

- [x] Все суммы передаются целыми копейками, включая доставку.
- [x] Авторизованная сверка защищает статус от поддельного callback и параметров браузера.
- [x] Повторы и неоднозначные ответы не создают повторные платежи.
- [x] Сохранены резервы, поздняя оплата, отмена, возвраты и уведомления.
- [x] Тесты протокола и бизнес-поведения проходят; реальные платежи выключены.

## Comments

Реализация ограничена payments/; настройки и потребители координируются с основным агентом. Старые платёжные записи не должны автоматически сверяться новым провайдером.

Общая проверка основным агентом: интеграция проверена, тесты/сборки пройдены. Рабочие подключения ожидают данных владельца; см. docs/ALFA-CDEK-READINESS.md.
