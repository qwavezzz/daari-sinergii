# Количество и тихое добавление
Status: done

Общий компонент управления количеством, синхронизация каталога / товара / корзины, доступность, ошибки сети, ограничения остатков, режим без JS и Pages.

## Comments

Единый шаблон счётчика, установка абсолютного количества через сессионный POST /cart/set/<product>/; повтор запроса не удваивает количество. В корзине сохранены защищённые update/remove. Добавление с JS не открывает drawer. Проверены фокус, ноль, остатки, другая вкладка, повтор после ошибки сети и отдельная статическая корзина Pages.
