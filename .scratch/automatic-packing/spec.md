# Автоматический подбор общей коробки

Status: implemented; VPS acceptance pending

Запрос 05.10.2026: заполнить пустые разделы коробок в админке, проверить их и
автоматически складывать совместимые товары в одну подходящую коробку.
Текущие измеренные схемы и отдельные посылки сохраняются. Новый режим automatic
использует подтверждённые размеры защищённой единицы и доступных коробок;
не требует отдельной схемы для каждой комбинации артикулов.

Ограничения: реальных замеров пока нет; учебные профили не разрешают рабочее
оформление. СДЭК получает места и оценивает доставку; выбор физической коробки
делает магазин из своего подтверждённого справочника. Пользователь подтвердил:
коробки покупаем у СДЭК. Добавлены выключенные черновики XS–XL со справочными
сведениями поставщика. Владелец выбрал прибавление цены каждой коробки к доставке;
этот режим установлен по умолчанию и для незаполненных профилей СДЭК.
Тариф и упаковка показываются отдельно. Фактические цены ещё не предоставлены.

Правила: размещение прямоугольных защищённых единиц без пересечений, внутри
полезных размеров с запасом у стенок; переворот только по разрешению, нагрузка
сверху ограничена; несовместимые группы раздельно. Вес включает единицы, тару,
скотч/наполнитель. В API внешние размеры округляются вверх. Предпочитать одну
коробку, если найдена допустимая укладка; иначе несколько. Поиск ограничен и
не доказывает глобальный оптимум. Сохранять позиции и инструкции для сборщика.

Приёмка: два разных товара в одной коробке; поворот; объём подходит, форма нет;
пределы веса и ПВЗ; запрет переворота/перегрузки сверху; разделение групп;
все единицы учтены ровно один раз; изменение профиля отменяет старый расчёт;
учебные записи отвергаются рабочим checkout; итог и упаковка сохранены в заказе.

Поставка: миграции, формы стандартной админки, отдельные учебные записи,
команда безопасного предпросмотра без заказа/накладной и тесты. Изменения VPS
выполняет владелец подготовленными командами; локальные результаты не считать VPS.

Реализация и локальная проверка завершены. Результаты: verification.md.
Реальные размеры и цена коробок ещё не предоставлены; черновики выключены.
