# Добавлять цену коробки к доставке

Status: deployed; positive-charge VPS preview passed; real prices pending

Владелец выбрал платную упаковку после реализации автоподбора. Существующий
расчёт уже суммировал `packing_price` по местам и добавлял к тарифу перевозчика;
нужно применить выбранную политику к создаваемым коробкам и прежним черновикам.

У новых коробок default `charge`; миграция 0013 переводит незаполненные
неучебные профили СДЭК в `charge`, сохраняя цены, явные прежние настройки и заказы.
Неизвестная цена остаётся NULL; параметры такого профиля не подтверждаются.
Для учебных профилей сохраняется их явно заданная тестовая политика.

Проверено: 32 теста автоподбора прошли, включая новую проверку четырёх товаров
в двух коробках (2 × 45,50 = 91 ₽; тариф 402,21 + 91 = 493,21 ₽), сохранение
суммы в заказе, запрет бесплатной подстановки при неизвестной цене и обновление
ранее созданных профилей без перезаписи цен и явных настроек.
Лог: `var/box-price-tests.log`.

На локальной БД применена миграция после копии
`var/backups/before-box-price-20261005T104749Z.sqlite3`: у пяти профилей СДЭК
установлен `charge`, цены NULL, коробки выключены. Ruff и проверка миграций прошли.
Код опубликован в `851c7faa8169b266c504c46597f1ee99443ace19`.
[CI](https://github.com/qwavezzz/daari-sinergii/actions/runs/37298984163) завершён
успешно целиком, включая PostgreSQL, миграции, восстановление и браузерные сценарии.
Обновлённый `var/releases/deploy-auto-packing.sh` скачивает именно этот архив,
сверяет SHA256 и допускает обновление с `store-3d39addbfc976` или `store-32a3a289430e`.
Проверены синтаксис Bash, встроенный Python и соответствие файлов архива.

Фактические цены XS/S/M/L/XL запрошены у владельца; до получения не подставлять
примерные или учебные значения в реальные профили.

05.10.2026 установка `store-851c7faa8169` подтверждена владельцем. В предпросмотре
получены `CDEK_RUB: 475.01`, `PACKAGING_RUB: 0.00`, `TOTAL_RUB: 475.01`,
`DECLARED_RUB: 2580.00`. Ноль соответствует явно заданному `included` у учебных
коробок; миграция изменяла незаполненные реальные профили и не перезаписывала
учебную политику. Этот запуск не подтверждает прибавление ненулевой цены на VPS.
Для отдельной проверки подготовлен `var/releases/check-box-price.sh` с условной
ценой 50 ₽ только у загруженных учебных коробок в памяти. Реальные профили и БД
не изменяются. Локально проверены синтаксис Bash, встроенный Python и выполнение
обоих сценариев с подменённым ответом CDEK: доплата 50/100 ₽ на одно/два места,
записи коробок остались неизменными. Запросов к внешнему API в локальной проверке
не было.

05.10.2026 владелец прислал успешный повторный запуск на VPS:

Проверка ненулевой цены за каждую коробку в предпросмотре на боевом сервере
пройдена. Первое `No such file or directory` относилось к отсутствию скрипта
до повторного запуска. 50 ₽ остаются учебной ценой только в памяти, настройки
карточек не изменились. Фактические цены, реальные замеры и оформление заказа
с ними через браузер на VPS остаются открытыми.
