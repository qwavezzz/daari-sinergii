# Уведомления о заказах

Status: implementation complete; SMTP setup pending

Только транзакционные письма. Пользователь отложил DNS-проверку, резервные копии, реальные товары и оплату. Внешний SMTP пока отсутствует. Адрес менеджера должен меняться через админку, без выпуска приложения.

Готовность: отдельные письма покупателю/менеджеру (HTML и текст), состав/суммы/получение, ссылка менеджера в Admin; события создания, оплаты, обработки, готовности, завершения, отмены и подтверждённых возвратов. Устойчивая очередь с ограниченным ожиданием SMTP и задержкой повторов. Замена адреса перенаправляет ещё не отправленные письма менеджеру. SMTP-секреты вне БД и Git. Покупательская ссылка сохраняет существующее ограничение сессии; письмо содержит все детали и адрес для ответа. Проверка в изолированной БД, без реальных писем и платежей.

Для реальной отправки остаётся регистрация почтового сервиса владельцем, подтверждение домена, ввод SMTP-секрета на VPS, выпуск кода и проверка доставки владельцем.
