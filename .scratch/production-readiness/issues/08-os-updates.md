## Уже выполнено: источник безопасности и симуляция

Пользователь показал `/etc/apt/sources.list.d/ubuntu.sources`: в `Suites` только
`noble noble-updates noble-backports`, компоненты `main restricted universe multiverse`,
ключ `/usr/share/keyrings/ubuntu-archive-keyring.gpg`. Источник `noble-security`
в этом файле отсутствует и в предыдущем выводе обновления индексов не появлялся.
Добавить официальный источник отдельным файлом, затем повторить обновление индексов
и симуляцию с учётом новых зависимостей:

```bash
sudo bash <<'BASH'
set -euo pipefail
umask 022
set -o noclobber
cat > /etc/apt/sources.list.d/ubuntu-security.sources <<'EOF'
Types: deb
URIs: http://security.ubuntu.com/ubuntu/
Suites: noble-security
Components: main restricted universe multiverse
Signed-By: /usr/share/keyrings/ubuntu-archive-keyring.gpg
EOF
apt-get update --error-on=any
apt-get -s --with-new-pkgs upgrade
BASH
```

`noclobber` останавливает выполнение при уже существующем файле источника;
`--error-on=any` не позволяет перейти к симуляции при ошибке обновления индексов.
Команды подтверждены выводом с VPS. Пакеты ядра могут требовать новых зависимостей;
вывод `kept back` сам по себе не доказывает явно установленный hold.
Фактическая установка, удаление пакетов и перезагрузка в текущий шаг не входят.
Подготовить план с учётом SSH/сети, резервной копии и проверки сервисов после обновления.

Источник: [руководство APT](https://manpages.debian.org/bookworm/apt/apt-get.8.en.html).
