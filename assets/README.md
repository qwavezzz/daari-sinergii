# Исходные материалы

Эта папка не раздаётся веб-сервером и не копируется в публичную сборку.

- `documents/` — 15 исходных PDF для `manage.py import_legacy_content`.
  Команда создаёт записи CMS и копирует документы в закрытое хранилище.
- `source/brand/` — официальный исходный логотип `logo-original.png` и утверждённые PNG
  с выделенным знаком и полной композицией.
- `source/photos/` — исходные изображения для подготовки публичных WebP.

Публичные производные хранятся в `public/assets/`. Для воспроизводимого кодирования
логотипа используется `scripts/assets/encode-brand.py`.

Три файла из прежней папки `Official Docs/` побайтово совпадали с копиями сайта.
Сохранена одна копия каждого документа:

| Название исходного документа | Файл |
| --- | --- |
| Генератор озона.pdf | `documents/ozone-generator-declaration.pdf` |
| Гидролаты.pdf | `documents/hydrolats-declaration.pdf` |
| Озонированные масла.pdf | `documents/ozonated-oils-declaration.pdf` |

Демонстрационные изображения товаров находятся в `apps/catalog/demo_assets/`.
Они не подтверждают внешний вид реальной продукции.
