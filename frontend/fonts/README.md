# Телефонные флаги

`phone-flags.woff2` — подмножество Google Noto Color Emoji для выбранных в магазине стран, лицензия SIL Open Font License: `phone-flags-LICENSE.txt`. Шрифт нужен для цветных эмодзи-флагов в Windows; загружается с сайта магазина, без внешнего запроса к Google Fonts.

Источник: https://fonts.google.com/noto/specimen/Noto+Color+Emoji. Лицензия: https://github.com/google/fonts/blob/main/ofl/notocoloremoji/OFL.txt. Подмножество создано fonttools: сохранены региональные индикаторы и 12 соответствующих им GSUB-лигатур (🇷🇺🇰🇿🇧🇾🇦🇲🇦🇿🇬🇪🇰🇬🇲🇩🇹🇯🇹🇲🇺🇿🇺🇦), `layout_closure=False`, `flavor=woff2`. Итоговый файл — 64 316 байт. Простое ограничение Unicode без списка лигатур сохраняет лишние комбинации флагов.
