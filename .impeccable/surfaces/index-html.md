# Home surface brief

## Scope and mode

- Scope: the Home route and its four presentation variants; the visual system propagates to six inner routes.
- Visitor mode: Persuade.

## Audience, job, action, and proof

- Primary audience: organizational buyers; secondary: private buyers.
- Job: identify the relevant direction and contact a specialist.
- Primary action: «Подобрать решение».
- Secondary action: «Получить консультацию».
- Proof currently available: none beyond the company direction brief. Evidence blocks remain explicit placeholders.

## Chosen direction

- Approved composition: `.impeccable/mocks/homepage-reactor-approved.png`.
- Shared thesis: a scroll-controlled ozone scan turns an atmospheric field into an explanatory interface.
- Four expressions: «Реактор O₃», «Белая лаборатория», «Водная колонна», and «Сечение среды».
- Memorable moment: the replaceable hero video aperture sits inside a controlled ozone field while anchored labels reveal categories, then the scene resolves directly into the three directions.
- Approved by delegation: the user explicitly asked the agent to propose the main technique and page contents.

## Composition inventory

| Ingredient | Commitment | Medium |
|---|---|---|
| Navigation | Compact brand, seven routes, one action, no oversized header | Semantic HTML/CSS |
| Hero headline | Maximum three lines, left anchored, remains intelligible before media | Semantic HTML/CSS |
| Video aperture | Replaceable local MP4/WebM boundary with a designed empty state | HTML5 video + CSS |
| Ozone field | Dense enough to read as a current, bounded to the hero, paused offscreen | Canvas 2D |
| Diagnostic labels | Two to four category labels anchored to the media boundary | HTML/CSS/SVG geometry |
| Primary action | Filled cyan rectangular control, never occluded | Semantic link |
| Variant switcher | Four compact named states, keyboard and URL addressable | HTML/CSS/JavaScript |
| Three directions | One continuous composition, not three generic cards | Semantic HTML/CSS |
| Product imagery | No false product photography; use honest media placeholders | HTML/CSS placeholders |
| Mobile | Linear content, reduced field density, no forced snap | Responsive CSS/JavaScript |

## Unresolved inputs

- Real hero video and poster.
- Real product photography.
- Verified quality evidence, specifications, certificates, cases, and contacts.
