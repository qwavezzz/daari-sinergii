# Дары Синергии

Одностраничный сайт компании, которая производит и монтирует системы озонирования воды, а также выпускает озонированные масла и гидролаты.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Ключевые файлы

- `src/App.jsx` — структура страницы, интерактивность и lifecycle hero-видео.
- `src/styles.css` — дизайн-система, сетка и адаптив.
- `DESIGN.md` — правила визуальной системы.
- `PRODUCT.md` — подтверждённый продуктовый контекст и ограничения формулировок.
- `PHOTO-PROMPTS.md` — актуальные промты и safe-зоны для концептуальных изображений.
- `HERO-VIDEO-PROMPT.md` — промт для генерации финального hero-видео в Gemini.

В hero подключено пользовательское видео: облегчённый VP9 WebM используется первым, H.264 MP4 служит резервным форматом, а WebP-постер остаётся статичным fallback для загрузки и `prefers-reduced-motion`. Файлы лежат в `public/assets/` и сохраняют текущую композицию и текстовый слой.
