# Дары Синергии

Одностраничный сайт компании, которая производит и монтирует системы озонирования воды, а также выпускает озонированные масла и гидролаты.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
```

## Ключевые файлы

- `src/App.jsx` — структура страницы, интерактивность и Canvas-анимация воды.
- `src/styles.css` — дизайн-система, сетка и адаптив.
- `DESIGN.md` — правила визуальной системы.
- `PRODUCT.md` — подтверждённый продуктовый контекст и ограничения формулировок.
- `HERO-VIDEO-PROMPT.md` — промт для генерации финального hero-видео в Gemini.

Текущий Canvas в hero — самостоятельная заглушка с инженерным диффузором и потоком микропузырьков в воде. Когда финальный ролик будет готов, его следует положить в `public/media/hero-ozone-water.webm` и `public/media/hero-ozone-water.mp4`, сохранив текущую композицию и текстовый слой.
