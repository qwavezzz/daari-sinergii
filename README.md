# «Дары Синергии»

Статический многостраничный презентационный сайт без сторонних runtime-зависимостей. Все семь маршрутов используют один источник фактического контента и поддерживают четыре варианта оформления.

## Запуск и сборка

Требуется только установленный Node.js; `npm install` не нужен.

- `npm run dev` — собрать сайт и запустить локальный сервер.
- Точный локальный адрес: `http://localhost:4173/` (сервер слушает `127.0.0.1:4173`).
- `npm run build` — пересобрать статические файлы в `dist/`.
- `npm run verify` — проверить уже собранные маршруты, ссылки, варианты и честные плейсхолдеры.
- `npm test` — выполнить чистую сборку и полную проверку.

Собранный сайт использует корневые URL, поэтому для просмотра `dist/` запускайте `npm run dev`, а не открывайте HTML двойным щелчком.

## Четыре презентационных варианта

Параметр `variant` имеет приоритет над сохранённым выбором. Выбор переносится во внутренние ссылки и сохраняется в `localStorage`.

| Вариант | ID | Прямая ссылка на главную |
|---|---|---|
| Реактор O₃ | `reactor-o3` | `http://localhost:4173/?variant=reactor-o3` |
| Белая лаборатория | `white-laboratory` | `http://localhost:4173/?variant=white-laboratory` |
| Водная колонна | `water-column` | `http://localhost:4173/?variant=water-column` |
| Сечение среды | `sectional-medium` | `http://localhost:4173/?variant=sectional-medium` |

Тот же параметр работает на любом маршруте, например `http://localhost:4173/contacts/?variant=water-column`. После выбора финального оформления переключатель отключается одним значением: `switcherEnabled: false` в `src/presentation-config.js`.

## Точки замены данных и материалов

- Видео и постер hero: заполнить локальные `poster` и `sources` в `src/interaction-config.js`. Добавить утверждённые файлы в проект и их копирование в `dist/` через `scripts/build.js`; удалённые URL не использовать.
- Контакты: заменить `content.contacts` в `src/site-content.js`.
- Подтверждения и доказательства: заменить `content.proof` там же; до проверки исходных материалов плейсхолдеры удалять нельзя.
- Описания направлений, области применения, аудитории и варианты продукции: заполнить соответствующие поля `directions` в `src/site-content.js`.
- Отраслевые сценарии и путь для частных покупателей: заполнить `industries` и `content.audiences.secondaryNote`.
- Подробные требования к медиа, допустимым схемам и безопасным областям кадра зафиксированы в `.scratch/dary-sinergii-site/asset-manifest.md`.

Форма на странице контактов демонстрационная: она проверяет поля и показывает состояния ошибки/успеха только в браузере. Данные не отправляются, не сохраняются и не имеют endpoint. Для реального приёма заявок нужен отдельно согласованный backend и политика обработки персональных данных.

## Что ещё требуется от заказчика

- окончательные телефон, электронная почта, адрес и режим работы;
- официальный логотип и правила его использования;
- принадлежащие компании локальные WebM/MP4 и постер hero;
- фотографии реального оборудования, масел, гидролатов, производства, команды и отраслевых контекстов;
- проверенные конфигурации и характеристики систем озонации;
- составы, объёмы, назначение и ограничения масел и гидролатов;
- подтверждённые сертификаты, документы, кейсы и результаты с точными подписями и правами публикации;
- при необходимости — утверждённые цены, отзывы и логотипы клиентов, только с доказательствами и разрешениями;
- лицензированные локальные файлы Onest и PT Mono, если требуется точное воспроизведение типографики;
- решение о финальном варианте оформления и момент отключения презентационного переключателя.
