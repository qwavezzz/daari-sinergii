# «Дары Синергии»

Статический многостраничный сайт без сторонних runtime-зависимостей.

## Локальные команды

- `npm run dev` — собрать сайт и запустить локальный сервер на `http://localhost:4173`.
- `npm run build` — сгенерировать семь маршрутов в `dist/`.
- `npm run verify` — проверить собранные маршруты, семантические ориентиры, ссылки и явные плейсхолдеры.
- `npm test` — выполнить чистую сборку и полную проверку.

Для команд достаточно установленного Node.js. Установка пакетов не требуется.

Фактический контент и заменяемые значения централизованы в `src/site-content.js`.
