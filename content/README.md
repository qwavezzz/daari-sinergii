# Редактирование содержимого

Вся текущая редакторская информация хранится в базе Django. JSON в `content/data/` — только снимок для первоначального переноса. Изменение этих файлов после импорта не меняет уже сохранённые записи.

`python manage.py import_legacy_content` переносит пять отраслевых сценариев, восемь подборок, 12 PDF, три декларации, тексты и существующие контакты. Команда проверяет входные PDF и копирует их из `public/documents/` в постоянный `PRIVATE_MEDIA_ROOT`. Для другого каталога исходных файлов используйте `--source-dir /path/to/public`. Повторный запуск добавляет отсутствующие исходные записи и сохраняет изменения текста, связей, адресов и статусов редактора. Отзывы, товары, цены, адрес доставки и юридические условия команда не выдумывает.

Редактор входит через `shop.dari-sinergii.ru/admin/`. Раздел «Тексты сайта» позволяет менять согласованные строки, не затрагивая анимированную структуру. Контакты находятся в отдельной форме. Для направлений, подборок, PDF, отзывов и видео доступны черновик, публикация, архив, порядок и дата публикации. Записи с будущей датой не видны до наступления даты. Действие публикации требует разрешения `publish_<model>`, дополнительно к обычным разрешениям Django. Изменения через админку попадают в журнал Django Admin.

Сначала сохраните запись как черновик, затем откройте ссылку «Закрытый предпросмотр». Она работает только на домене админки и проверяет права пользователя. Черновые файлы нельзя получить через публичный адрес или параметр запроса. Админка не позволяет вставлять произвольный HTML или iframe. Тексты выводятся с экранированием.

PDF открываются и скачиваются через `/documents/<slug>/`, скачивание — с `?download=1`. Замена файла в одной записи обновляет ссылки во всех подборках и товарах. Изменение slug сохраняет переадресацию с прежнего адреса. Для первоначальных файлов сохранены совместимые пути `/documents/materials/*.pdf` и `/documents/*-declaration.pdf`. Архивирование или снятие с публикации закрывает и текущий, и прежние адреса.

Хранилище `PRIVATE_MEDIA_ROOT` нельзя раздавать через публичный `alias` Nginx; файлы выдаёт проверяющее публикацию представление Django. Исходную папку `public/documents/` также нельзя копировать в публичную статику нового сайта. Имена загружаемых файлов преобразуются в UUID; русские названия остаются в карточках документов. PDF проверяются по расширению, заголовку и лимиту размера (30 МБ по умолчанию). Изображения — JPG/PNG/WebP, проверяются Pillow, максимальный размер 8 МБ и 40 млн пикселей.

Отзывы добавляет сотрудник. Для публикации обязательны автор, текст, дата и внутреннее основание публикации. Основание не попадает на сайт. Товары и направления связываются в форме отзыва; признак «Показывать на главной» выводит отзыв между продукцией и отраслевыми сценариями. При отсутствии записей блок скрыт. На главной показываются первые 24 опубликованных отзыва согласно порядку.

Для видео указываются поддерживаемый провайдер и идентификатор ролика, без HTML и URL. Предусмотрены Rutube, YouTube и Vimeo, но публикация закрыта до согласования провайдеров в `CONTENT_VIDEO_PROVIDERS`. Разрешённые значения настраиваются сервером; по умолчанию список пустой. Видео открывается обычной ссылкой на сервис, обложка необязательна. Прямая загрузка видео не включена. На главной показываются первые 12 опубликованных видео.
