# Контрольное письмо для показа клиенту

Команда использует работающий релиз и настройки SMTP из `/etc/dari/dari.env`.
Отправляет одно письмо на явно указанный собственный ящик, без создания заказа
или обработки очереди. Контрольный код помогает отличить новое письмо от старых.

## Основной способ: небольшой скрипт

Разработчик выбрал другой собственный ящик и введёт адрес сам. В локальном
PowerShell из папки проекта загрузить один файл:

```powershell
scp .\deploy\send-client-test-email.sh root@134.0.113.203:/root/
```

На VPS выполнить одной строкой:

```bash
sudo bash /root/send-client-test-email.sh
```

На приглашение `Email for the test message:` ввести адрес своего ящика и Enter.
Скрипт проверит формат адреса, отправит одно письмо и напечатает MAIL_ACCEPTED/TEST_CODE.
Существующие адреса магазина не меняются. Повторять запуск без необходимости
не нужно: каждый успешный запуск отправляет новое письмо.

Исходный `.sh` хранится с LF, чтобы прямая передача через scp не ломала Bash.

## Альтернатива: команда без загрузки файла

Выполнить в терминале VPS под root. Получатель в примере — собственный ящик
сайта `orders@dari-sinergii.ru`. Для другого своего ящика заменить только строку
`recipient = ...`. Пароли в команду не вставляются.

```bash
systemd-run --quiet --wait --pipe --collect \
  --uid=dari --gid=www-data -p SupplementaryGroups=dari \
  --working-directory=/srv/dari/current \
  -p EnvironmentFile=/etc/dari/dari.env \
  /srv/dari/current/.venv/bin/python manage.py shell -c '
from uuid import uuid4
from django.conf import settings
from django.core.mail import send_mail
from django.utils import timezone

recipient = "orders@dari-sinergii.ru"
if settings.EMAIL_BACKEND != "django.core.mail.backends.smtp.EmailBackend":
    raise SystemExit("Остановлено: требуется действующий SMTP backend.")
code = uuid4().hex[:8].upper()
stamp = timezone.now().strftime("%Y-%m-%d %H:%M:%S UTC")
subject = f"Проверка почты — Дары Синергии — {code}"
body = (
    "Здравствуйте!\n\n"
    "Это контрольное письмо с сайта «Дары Синергии».\n"
    "Оно отправлено из рабочего приложения через SMTP REG.RU.\n\n"
    f"Время проверки: {stamp}\nКонтрольный код: {code}\n\n"
    "Письмо предназначено для проверки доставки уведомлений сайта.\n"
)
sent = send_mail(subject, body, settings.DEFAULT_FROM_EMAIL, [recipient], fail_silently=False)
if sent != 1:
    raise SystemExit("SMTP не подтвердил отправку одного письма.")
print("MAIL_ACCEPTED:", sent)
print("TEST_CODE:", code)
print("Получение подтвердить в почтовом ящике по этому коду.")
'
```

Открыть https://webmail.hosting.reg.ru/, найти письмо по теме/коду, проверить
отправителя и время. Для показа клиенту достаточно открыть это письмо; в снимок
экрана не включать другие сообщения и данные входа. Если письма нет во входящих,
проверить папку «Спам». Повторную отправку делать только по необходимости.

`MAIL_ACCEPTED: 1` означает принятие письма SMTP-сервером. Доставку подтверждает
письмо в ящике, а не эта строка. Тест своего ящика REG.RU не доказывает приём
внешними почтовыми сервисами и прохождение SPF/DKIM/DMARC на их стороне.

Этот тест не проверяет всю цепочку заказа, таймер или платёжку. Готовые шаблоны
уведомлений можно показать отдельно; демонстрационное письмо не подменяет
реальный заказ. Реальные заказы и адреса покупателей ради проверки не менять.

Повторная проверка 21 сентября пока не выполнена: ожидаются вывод с кодом и
подтверждение получения разработчиком. Проверка 18 сентября была успешной.
