# Архив исходных материалов

Эти файлы сохраняют историю проекта и не входят в архив приложения,
создаваемый `scripts/package-release.py`.

- `design-references/`: исходные референсы дизайна, прежде `references/`.
- `deploy/`: датированные отчёты и разовые инструкции прежних выпусков.

Архивные команды, пути и сведения о состоянии VPS могут быть неактуальны.
Действующий порядок: [подготовка магазина](../docs/STORE-LAUNCH.md) и
[развёртывание](../deploy/README.md).
