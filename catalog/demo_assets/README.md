# Иллюстрации демонстрационного каталога

Созданы через imagegen 11 сентября 2026 для вымышленных позиций по запросу пользователя.
Это концепты возможной упаковки и оборудования, а не фотографии реальной продукции.
Названия, цены, размеры и составы в `catalog/demo_data.py` также демонстрационные.

Шесть WebP (29–78 КБ каждый) используются как общие изображения форматов:
масло 30/50 мл, гидролат 100/200 мл, оборудование и набор. Разрешение 1254 × 1254.
Для публикации реального ассортимента заменить их подтверждёнными фотографиями каждого артикула.

Оригиналы генерации сохранены локально в `artifacts/demo-catalog/sources/` и в каталоге generated_images Codex.
WebP закодированы Pillow с quality=86, method=6, без изменения размеров и композиции.
Команда импорта копирует изображения в приватное хранилище товара; публичный URL проверяет его публикацию.
