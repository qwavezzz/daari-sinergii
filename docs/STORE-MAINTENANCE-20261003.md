# Обновление магазина — 3 октября 2026

## Изменения

- Пример телефона: код страны слева и `(999) 123 45 67` в поле; подсказка `+7 (999) 123 45 67`.
- Email проверяется при уходе из поля; сообщение доступно экранному диктору и снимается после исправления. Серверная проверка сохранена.
- Публичная оферта, политика, доставка и возвраты имеют нумерованные положения, оглавление, реквизиты из настроек магазина и стили печати. Подтверждённый владельцем срок передачи оплаченного заказа — 1–3 рабочих дня.
- Политика отражает OpenStreetMap, серверные запросы к СДЭК, обработку координат в браузере и оплату через Альфа-Банк.
- Стандартные документы находятся в `apps/content/data/customer_pages.json`. Команда `setup_customer_pages --refresh-defaults` обновляет только пустые поля и известные стандартные редакции. Правки владельца сохраняются с предупреждением в выводе. `deploy/update-app.sh` выполняет эту команду при обновлении.
- По просьбе владельца адрес продавца и адрес возврата пока оставлены пустыми.

## Что установлено по доставке

Проверено на публичном магазине 03.10.2026: ПВЗ загружаются; расчёт возвращает HTTP 422. Прямой запрос к `api.edu.cdek.ru/v2/calculator/tariff` с официальной публичной тестовой учётной записью возвращает HTTP 400 и код `v2_sender_location_not_recognized`. Справочник `location/cities` возвращает `[]` как для Тольятти (431), так и для Москвы (44) и общего запроса городов РФ. Добавление/удаление страховки результата не меняет.

Это наблюдение указывает на недоступность справочника в тестовой среде, а не на ошибку коробки или карты. Владелец подтвердил отсутствие рабочих API-ключей и попросил сохранить тестовый режим. Подмена города, произвольный тариф или бесплатная доставка не добавлялись. Восстановление реального расчёта **не подтверждено**; требуется восстановление сервиса СДЭК.

Проверка на VPS из текущего релиза, без создания заказа или отправления:

```bash
sudo systemd-run --quiet --wait --pipe --collect \
  --uid=dari --gid=www-data -p SupplementaryGroups=dari \
  --working-directory=/srv/dari/current \
  -p EnvironmentFile=/etc/dari/dari.env \
  /srv/dari/current/.venv/bin/python manage.py check_cdek_connection --pvz TLT1
```

Команда выводит среду, город отправления и безопасные коды ответа СДЭК, не раскрывая ключи. После восстановления справочника должна вывести стоимость и срок. Затем нужно повторить расчёт в браузере для фактической корзины и нужного ПВЗ.

## Очистка

Удалены настройки прежнего платёжного провайдера, неиспользуемые городские/геолокационные маршруты и прокси прежнего виджета СДЭК, дублирующие обработчики/шаблоны юридических страниц, старые шаблоны писем и неиспользуемые CSS-правила. Исторические платёжные записи и цепочка миграций сохранены: они нужны для корректного учёта и обновления существующих баз.

Служебная проверка VPS теперь использует актуальные импорты `apps.*` и настройку Альфа-Банка. Упаковщик релиза больше не содержит жёсткого списка файлов старой поставки: удалённые исходники исключаются, новые требуют явного `--include`, результат сохраняется в `var/releases/`.

Удалены 2 803 файла (587 161 442 байта) из трёх временных директорий: два проверенных снимка прошлых коммитов и 792 копии исходных файлов в тестовом медиахранилище. Каждый файл медиахранилища сопоставлен с оригиналом по SHA256; исходники снимков сверены с Git, остаток — кэши Ruff/Vite. Также удалён чистый старый worktree Pages (около 250 МиБ). Тестовый сервер теперь очищает собственное одноразовое медиахранилище перед импортом, предотвращая повторное накопление PDF.

Оригиналы документов, изображений, лицензии, рабочие загрузки и базы данных не являются мусором. Их наличие на диске само по себе не влияет на выполнение страниц; в сборку сайта попадают только подключённые ресурсы.

## Обновление VPS

Публичный VPS этим выпуском автоматически не обновлялся. Выполнить от root на существующей установке:

```bash
bash <<'BASH'
set -euo pipefail
umask 0022
test "$(id -u)" -eq 0
commit=4dfd81dd4ac747f3a17fc8db1667b94053e5cd4b
release_dir="/srv/dari/releases/store-${commit:0:12}"
test ! -e "$release_dir"
git clone --branch main --single-branch \
  https://github.com/qwavezzz/daari-sinergii.git "$release_dir"
git -C "$release_dir" checkout --detach "$commit"
test "$(git -C "$release_dir" rev-parse HEAD)" = "$commit"
bash "$release_dir/deploy/update-app.sh" "$release_dir"
BASH
```

Скрипт проверяет конфигурацию, делает штатную резервную копию, обновляет стандартные документы и переключает приложение, сохраняя `/etc/dari/dari.env`. Рабочие платежи или рабочий договор СДЭК не включаются. Успешное завершение обозначается `UPDATE_OK`. При ошибке нужно сохранить вывод и проверить причину; повторно запускать установку вслепую не следует.
