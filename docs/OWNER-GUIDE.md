# Работа с сайтом для владельца

Админка: https://shop.dari-sinergii.ru/admin/. Для ежедневной работы выдаются
индивидуальный пользователь с флагом «Статус персонала» и группы
«Контент-редактор» / «Менеджер магазина». При необходимости владелец получает
обе группы. Суперпользователь нужен для управления пользователями и настройками
магазина; его лучше держать как отдельный административный доступ.

| Что изменить | Где |
|---|---|
| Телефон, email, адрес, юридическое наименование | Контент → Контакты и сведения о компании |
| Тексты лендинга, title и description главной | Контент → Тексты сайта; поля `home_meta_title`, `home_meta_description` |
| Страницы библиотеки | Контент → Тематические подборки |
| PDF, название, публикацию | Контент → Документы |
| Отзывы и фотографии | Отзывы |
| Категории, карточки, цены, фото, остатки | Каталог |
| Получателя уведомлений и адрес для ответов | Заказы → Почтовые уведомления |
| Историю отправки, попытки и ошибки | Заказы → Email-уведомления |
| Условия и политику | Заказы → Настройки магазина, доступ суперпользователя |
| Пароли, сотрудников, группы | Пользователи / группы, доступ суперпользователя |

Тексты, материалы и товары меняются без программирования и пересборки.
Сначала сохраняйте документы как черновик и открывайте защищённый предпросмотр.
Публикация делает файл доступным посетителям; архив скрывает его. После изменения
проверьте результат в отдельной вкладке без входа в админку.

Подробности: [контент](../content/README.md), [магазин](../orders/README.md),
[почта](../deploy/EMAIL.md), [паспорт доступов](CLIENT-ACCESS.template.md).

## Первичная настройка перед передачей

Разработчик входит существующим суперпользователем и заполняет согласованные
с владельцем сведения. Если в разделе одиночной настройки уже есть запись,
редактировать её; если нет — создать через «Добавить».

1. В «Контакты и сведения о компании» заполнить название, юридическое наименование,
   email, адрес и оба поля телефона. «Телефон для ссылки» — международный номер
   без пробелов, например `+79991234567`; «Телефон для отображения» — читаемый формат.
2. В «Тексты сайта» найти по ключу `home_meta_title` и `home_meta_description`.
   Изменить поле «Текст» на согласованные заголовок и описание. Проверить остальные
   тексты на заглушки и устаревшие сведения; ключи полей не менять.
3. В «Почтовые уведомления» задать «Email менеджера» и «Email для ответов покупателей».
   Если заказы и вопросы обрабатываются в `orders@dari-sinergii.ru`, указать этот
   ящик в обоих полях. Если ответственным выбран другой ящик — указать его.
   Это адреса назначения, SMTP-пароль через эти поля не меняется.
4. В «Настройки магазина» внести полученные от владельца политику и условия.
   «Оформление включено» оставить выключенным. До выбора оплаты/доставки
   не публиковать вымышленные способы, сроки или условия.

## Отдельная учётная запись владельца

Суперпользователь открывает «Пользователи» → «Добавить пользователя», задаёт
отдельный логин и пароль, сохраняет и открывает страницу прав нового пользователя.
Включить «Активный» и «Статус персонала», назначить группы «Контент-редактор»
и «Менеджер магазина», затем сохранить. «Статус суперпользователя» для ежедневной
работы не требуется. Управление сотрудниками и настройками магазина доступно
через отдельный административный аккаунт владельца.

Проверить новый вход в другом браузере или приватном окне: доступны контент,
каталог и адреса уведомлений. Одного создания пользователя без «Статуса персонала»
недостаточно для входа в админку.

## Короткая приёмка

- Под новым пользователем открыть контакты и сохранить согласованное изменение;
  проверить его на основном сайте без авторизации.
- Создать черновик товара с изображением и черновик PDF-документа с предпросмотром.
  Проверить сохранение и загрузку, не публикуя пробные материалы.
- На публичном сайте открыть главную, тематическую подборку и опубликованный PDF.
- В демомагазине проверить карточку и корзину; оформление и оплата остаются выключены.

После заполнения контента подключить кабинеты по [инструкции SEO](SEO-SETUP.md)
и заполнить приватный паспорт доступов. Подтверждение кабинетов и ручную приёмку
отмечать выполненными только по фактическому результату владельца/разработчика.

Сейчас в магазине демонстрационные товары. Можно пользоваться корзиной, но
покупки и платежи выключены. Перед реальным запуском нужно снять с публикации
`DEMO-*`, заполнить реальный ассортимент, утвердить документы и отдельно
подключить получение/оплату. Не переключайте технические флаги самостоятельно.

SMTP-пароли, DNS, серверные обновления и резервные копии обслуживает технический
ответственный. Дизайн, структура анимаций и новые функции также требуют разработчика.
Сайт не предоставляет визуальный конструктор произвольных страниц.

Если письмо не пришло: проверьте адрес менеджера, очередь уведомлений и папку
«Спам». Статус «Отправлено» означает принятие SMTP-сервером; окончательную доставку
проверяют в почтовом сервисе. Не создавайте повторный заказ ради письма.
