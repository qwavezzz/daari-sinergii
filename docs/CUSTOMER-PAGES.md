# Страницы покупателей и доставка

> Обновление 01.10.2026: актуальные условия запуска и подключение Альфа-Банка/СДЭК описаны в [ALFA-CDEK-READINESS.md](ALFA-CDEK-READINESS.md). Ниже сохранён отчёт предыдущего этапа; фиксированный тариф 300 ₽ и прежние результаты проверок относятся к нему. В новой реализации доставка рассчитывается сервером после выбора ПВЗ. Для обновления стандартных текстов используйте `setup_customer_pages --refresh-defaults --dry-run`, затем применение после просмотра.

Реализовано 30.09.2026. Одинаковое содержимое доступно на основном домене и в магазине;
основной домен указан каноническим. Все семь разделов — HTML-страницы:

- `/legal/privacy/` — политика обработки персональных данных;
- `/legal/terms/` — условия покупки;
- `/delivery-and-payment/` — доставка и оплата;
- `/returns/` — возврат и отмена;
- `/contacts/` — контакты и реквизиты;
- `/product-documents/` — перечень деклараций с метаданными и ссылками на оригиналы;
- `/faq/` — вопросы и ответы.

## Установка

В окружении Django применить миграции и заполнить новые разделы:

```powershell
python manage.py migrate
python manage.py setup_customer_pages
npm run build
python manage.py collectstatic --noinput
```

Для локальной разработки добавлять `--settings=config.settings_dev` к командам Django.
Команда заполнения сохраняет непустые тексты и существующий тариф, не включает оформление
или настоящие платежи. Начальные данные: СДЭК до ПВЗ по России, 300 ₽ за заказ и 12 FAQ.
Если декларации ещё не импортированы в новую базу, выполнить существующую команду
`python manage.py import_legacy_content` с соответствующими настройками окружения.
Повторный импорт сохраняет существующие документы. Не загружать PDF как замены новым HTML-страницам.

## Где редактировать

| Что | Раздел админки |
| --- | --- |
| Тексты всех страниц и вводный текст FAQ | Заказы → Настройки магазина |
| ФИО ИП / наименование, тип продавца, ИНН, ОГРН/ОГРНИП, КПП, регистрирующий орган, телефон, email, адреса, часы связи, банковские реквизиты | Содержимое → Контакты и сведения о компании |
| Вопросы, ответы, порядок, видимость | Содержимое → Вопросы и ответы |
| Стоимость доставки, доступность и ставка НДС | Заказы → Способы получения → СДЭК — пункт выдачи по России |
| Декларации, номера, сроки, оригиналы, публикация, связь с товарами | Содержимое → Документы |

Права полного управления доступны администратору. При использовании ограниченных ролей
выдать необходимые права просмотра и изменения соответствующих моделей; управление
флагом оформления остаётся ответственностью владельца.

Тексты вводятся обычными абзацами. Строка `## Заголовок` становится заголовком раздела.
HTML и код шаблонов не исполняются. Поддержаны переменные `{company_name}`, `{legal_name}`,
`{email}`, `{phone}`, `{delivery_price}`, `{main_url}`, `{shop_url}`.
Переменная цены не содержит знак рубля. При смене тарифа она обновляется и в FAQ.
При повторном запуске команды FAQ добавляется только в полностью пустой раздел.

## Доставка и деньги

Стоимость хранится в `DeliveryMethod.price`; способ с флагом «По умолчанию в корзине» выбран
при первом открытии оформления. Без такого флага используется первый доступный способ по порядку.
Пустая корзина не имеет платы за доставку. Для нескольких товаров плата начисляется один раз.
Покупатель вручную указывает город и адрес ПВЗ; дана ссылка на официальную карту СДЭК.
Проверка кода ПВЗ через API, автоматическое создание накладных и расчёт тарифа СДЭК не добавлены.

При оформлении сохраняются цена доставки, ставка НДС и принятые тексты. Последующее изменение
тарифа не меняет готовый заказ или его платёж. Если тариф изменился до подтверждения,
покупателю предлагается подтвердить новую сумму. Альфа-Банк получает общую сумму товаров и доставки.
При включённых чеках доставка передаётся отдельной позицией `service` с количеством 1.

До настоящей оплаты нужно выбрать ставку НДС доставки с бухгалтером. Она намеренно не угадана:
при пустой ставке формирование чека для платной доставки блокируется. Для старых заказов без
сохранённой ставки она также не подменяется текущими настройками. Налоговые параметры товаров
настраиваются отдельно. Действующий признак расчёта `full_payment` сохранён; если бизнес использует
предоплату с последующим зачётом, согласовать и настроить соответствующий кассовый процесс до запуска.

## Что заполняет владелец

Подтверждённые имя ИП, телефон и email внесены. ИНН, ОГРНИП, адреса и часы работы оставлены
пустыми по указанию владельца; на сайте пустые строки реквизитов не выводятся.
Нужно дополнить эти поля и срок подготовки к отправке, проверить соответствие политики
фактически привлечённым исполнителям, срокам хранения и процессам обработки данных.
У СДЭК нет единого срока для всей России: на странице дана ссылка на расчёт по маршруту.
Подготовленные тексты не означают одобрения эквайринга или включения приёма заказов.

## Проверка реализации

Из 107 Django-тестов 106 прошли, один тест конкурентности для PostgreSQL пропущен на SQLite.
Проверены изменение тарифа через админку, 690 + 300 = 990 в корзине/заказе/платеже/чеке,
неизменность оформленных заказов, отсутствие платы за пустую корзину и безопасный вывод текстов.
В браузере проверены все 7 страниц на обоих доменах при ширинах 1440 и 390 px,
оформление до локального заказа и FAQ без JavaScript. Реальные списания не выполнялись.
Сборки Django-фронтенда и Pages проходят; статический экспорт также включает новые разделы
и демонстрационную доставку из той же настройки. Независимая визуальная проверка: `ship`.
