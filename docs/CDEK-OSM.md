# ПВЗ СДЭК на OpenStreetMap

Расчёт упаковки описан в [инструкции по упаковке и точности СДЭК](PACKING-AND-CDEK.md): подтверждённые схемы общих коробок, отдельные посылки, ограничения выбранного ПВЗ, объявленная стоимость и сборка по сохранённому заказу.

На странице `/checkout/` при выборе доставки СДЭК карта видна сразу и автоматически загружает ПВЗ. Близкие точки объединяются в круги с количеством; нажатие приближает группу, при увеличении масштаба появляются отдельные адреса. Карта остаётся видимой после выбора пункта. Ручного ввода кода и кнопок показа/скрытия нет.

Поиск «Город или адрес» фильтрует официальный справочник ПВЗ; «Рядом со мной» с разрешения браузера перемещает карту к покупателю. Пункты доступны также в списке текущей области. Только Россия, только ПВЗ с выдачей заказов, без постаматов.

## Настройка

Для проверки на локальной демобазе после `migrate` запустите:

```powershell
python manage.py setup_working_checkout
```

Команда создаёт активный способ «СДЭК — пункт выдачи», выбирает его по умолчанию и добавляет учебные вес/размеры только товарам `DEMO-*`. Она работает лишь в локальном тестовом режиме с пробной оплатой и выключенным Альфа-Банком. Одного запуска `runserver` недостаточно, если в старой базе ещё нет способа доставки СДЭК. Учебные упаковки не подходят для расчётов реальных отправлений.

Карта использует локальные сборки Leaflet 1.9.4 и Supercluster 8.0.1. Ключ Яндекс Карт больше не нужен. По умолчанию:

```dotenv
CDEK_ENABLED=true
CDEK_TEST_MODE=true
CDEK_CLIENT_ID=
CDEK_CLIENT_SECRET=
CDEK_FROM_CITY_CODE=431
CDEK_MAP_TILE_URL=https://tile.openstreetmap.org/{z}/{x}/{y}.png
CDEK_MAP_ATTRIBUTION=
```

`431` — существующая локальная настройка города отправления (Тольятти); перед рабочим запуском подтвердите город отправителя в справочнике СДЭК. В админке у способа получения должен быть выбран провайдер СДЭК и нужный тариф; у товаров — вес и размеры упаковки. Оформление заказа также должно быть включено в настройках магазина.

В `config.settings_dev` при пустых личных ключах и `CDEK_PUBLIC_SANDBOX=true` используется опубликованный СДЭК тестовый аккаунт. Собственные тестовые ключи задаются в `.env`, не в JavaScript. Для работы с боевым справочником нужны рабочие ключи и `CDEK_TEST_MODE=false`. Переключение окружения не меняет карту и не включает настоящую оплату. Приложение проверяет ПВЗ и рассчитывает доставку; накладную автоматически не создаёт.

После изменения зависимостей выполните `npm ci` и `npm run build`, затем перезапустите Django. Геолокация работает на HTTPS и локальном `localhost`; по обычному HTTP на внешнем адресе используйте ручной поиск города.

## Данные и поведение

- `/checkout/cdek/map-points/` выдаёт нормализованный справочник страницами по 500. Интерфейс автоматически загружает все страницы и устраняет повторы по коду ПВЗ. Пока загрузка не завершена, показан её прогресс. При сбое остаются уже загруженные пункты и кнопка продолжения загрузки. Поиск по городу/адресу работает локально по этому справочнику и не зависит от геокодера СДЭК.
- Начальная область — город отправления, когда его точки доступны. Геолокация, поиск или ручное перемещение карты меняют её; поздние страницы справочника не возвращают пользователя к начальной области.
- Список синхронизирован с текущей областью карты и показывает строки порциями по 50. «Показать ещё пункты» расширяет список уже загруженных данных. Поиск и список не создают дополнительные запросы справочника.
- Расстояние приблизительное, по прямой, а не маршрут пешком. Карта группирует близкие отметки; нажатие на группу приближает их.
- Пункт без корректных координат остаётся доступен в списке. Ошибка тайлов или отказ в геолокации не блокируют ручной выбор.
- Разрешение на геолокацию запрашивается только после нажатия кнопки. Координаты используются в памяти браузера для перемещения карты и расстояния; интерфейс не отправляет их серверу приложения или СДЭК и не записывает в заказ/сессию. Поставщик карты получает обычные запросы тайлов для просматриваемой области.
- Сервер повторно проверяет код выбранного ПВЗ, страну, возможность выдачи и ограничения веса, получает цену СДЭК и подписывает расчёт для текущей корзины и сессии. Смена города, пункта или корзины аннулирует предыдущий расчёт.
- Справочник кэшируется на пять минут. Ключи кэша разделены по окружению и аккаунту СДЭК. Учётные данные не попадают в браузер.

## Бесплатная карта

Публичные тайлы OpenStreetMap не требуют API-ключа, но предоставляются без гарантии доступности и с [правилами использования OSM](https://operations.osmfoundation.org/policies/tiles/). В интерфейсе сохранена видимая атрибуция, разрешён Referer, работает обычный браузерный кэш. Нет массовой загрузки тайлов и офлайн-предзагрузки.

При необходимости смените `CDEK_MAP_TILE_URL` на HTTPS-шаблон другого поставщика с `{z}`, `{x}`, `{y}` и одним явным доменом (без `{s}`). Дополнительную текстовую атрибуцию задаёт `CDEK_MAP_ATTRIBUTION`; подпись OpenStreetMap сохраняется. CSP автоматически разрешает изображения с этого домена только на оформлении заказа. При ошибочной конфигурации остаётся список.

## Проверка

```powershell
.venv/Scripts/python.exe manage.py test --settings=config.settings_test --noinput
npm run check:js
npm run build
npm run test:browser -- tests/browser/cdek.spec.js
```

Браузерные автотесты используют настоящие Leaflet/Supercluster, отдельную тестовую базу, искусственные ПВЗ и тайлы. Они не обращаются к публичному серверу карт. Отдельная ручная проверка на локальной демобазе использовала реальные ответы sandbox СДЭК и настоящие тайлы; её скриншоты находятся в `var/artifacts/cdek-always-map/`.

Проверка 2026-10-01: исправлена причина таймаутов — принудительный заголовок `Connection: close` в urllib. HTTPS-клиент теперь использует стандартное соединение HTTP/1.1 и закрывает его после чтения ограниченного ответа; перенаправления не выполняются. Sandbox вернул 1280 ПВЗ России, включая 8 ПВЗ Тольятти. В браузере на локальной базе проверены поиск, кластеры, выбор адреса и ответ калькулятора 156 ₽ для учебной посылки 400 г, 20 × 10 × 10 см. Это тестовый тариф; перед рабочим запуском нужны боевые ключи и реальные измерения упаковок. Контракт запросов сверялся с [официальной документацией СДЭК API v2](https://apidoc.cdek.ru/).
