# Учебная доставка для проверки оформления

Пока калькулятор тестовой среды СДЭК возвращает ошибки, можно явно включить учебную стоимость **500 ₽ за весь заказ**. Это вымышленная сумма, не тариф СДЭК. Срок доставки не рассчитывается. Режим согласован владельцем как временная возможность пройти пробный заказ; он не подтверждает исправность калькулятора перевозчика.

## Включение на VPS

Сначала установите выпуск с поддержкой `CDEK_DEMO_QUOTES_ENABLED` через `deploy/update-app.sh`, как описано в `deploy/README.md`. Скрипт обновления сохраняет файл окружения.

Откройте `/etc/dari/dari.env` и задайте следующие значения (замените существующие строки, не оставляйте дубликаты):

```dotenv
CDEK_ENABLED=true
CDEK_TEST_MODE=true
CDEK_DEMO_QUOTES_ENABLED=true
CDEK_FROM_CITY_CODE=431
PAYMENT_STUB_ENABLED=true
ALFABANK_ENABLED=false
```

Существующие тестовые `CDEK_CLIENT_ID` и `CDEK_CLIENT_SECRET` сохраните: они нужны для проверки выбранного ПВЗ. Не включайте `DEBUG` и не меняйте `DJANGO_SETTINGS_MODULE=config.settings`.

```bash
sudo systemctl restart dari.service
sudo systemctl is-active dari.service
curl --fail --silent --show-error https://shop.dari-sinergii.ru/health/
```

Откройте оформление заново и выберите ПВЗ. До выбора пункта и после него должна быть надпись «Учебная доставка — 500 ₽ … это не тариф СДЭК». Затем доступна пробная оплата без банковской карты и списания денег. Эта пометка сохраняется на странице пробной оплаты, заказа и в административной части.

Режим работает только при тестовом СДЭК, включённой пробной оплате и выключенном Альфа-Банке. При несовместимых настройках оформление с такой доставкой блокируется с объяснением. Если справочник ПВЗ тоже недоступен, режим не подставляет вымышленный пункт.

## Что проверяется

- Подлинность выбранного ПВЗ через тестовый API и его ограничения по весу.
- Существующая система упаковки и её ограничения. Тестовые схемы остаются тестовыми; режим не подтверждает замеры.
- Подписанная сервером цена, привязка к корзине, сессии и выбранному ПВЗ, срок действия расчёта.
- 500 ₽ за весь заказ независимо от числа коробок. Варианты упаковки сравниваются по числу мест, объёму и весу при одинаковой учебной цене, без обращения к калькулятору. `packing_comparison.scope=demo_fixed_price` не означает сравнение тарифов перевозчика.
- Отсутствие банковских операций, писем о реальной оплате, накладной и отправки. Завершение пробы освобождает резерв товара, не списывая складской остаток.

Источник суммы сохраняется в `Order.delivery_snapshot.price_source=demo`. Эти заказы навсегда исключены из банковской оплаты, в том числе после отключения учебного режима. Изменения схемы базы не требуются.

## Возврат к тарифам СДЭК

Установите `CDEK_DEMO_QUOTES_ENABLED=false` и перезапустите `dari.service`. Откройте оформление заново: прежние подписанные расчёты станут недействительными. Калькулятор снова будет обращаться к API; его ошибки будут показаны пользователю. Автоматической подмены тарифа на учебную цену нет.

Команда `check_cdek_connection` продолжает проверять настоящий API и может сообщать об ошибке калькулятора даже при работающей учебной доставке. Для реальных продаж необходимы рабочий договор, ключи, проверенные замеры и контрольные расчёты.
