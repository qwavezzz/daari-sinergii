# Автоподбор по подтверждённым исходным замерам

Status: accepted

Требование владельца: совместимые товары автоматически помещаются в общую
подходящую коробку СДЭК, без ручного создания схемы на каждую комбинацию.

Добавлен отдельный режим товара automatic. Индивидуальные посылки и измеренные
схемы сохраняются. Автоподбор использует подписанные подтверждения защищённых
единиц и коробок, осевую укладку, разрешённые повороты, группы совместимости,
полную опору и допустимую нагрузку сверху. Суммирование объёмов служит только
условием отсева; положительный результат требует явных непересекающихся позиций.

Приоритет — наименьшее найденное число мест, затем полная стоимость получения
среди проверенных API вариантов. Ограниченный поиск не гарантирует глобального
оптимума. При исчерпании бюджета нельзя подменять результат приблизительной
ценой. Габариты для API — внешние размеры коробки с округлением вверх.

Цена упаковки хранится отдельно от тарифа перевозчика. Владелец выбрал добавление
цены коробки к доставке за каждое место; это режим по умолчанию для новых коробок.
Незаполненные профили СДЭК переводятся в него миграцией. Ранее явно заданные
политики и цены сохраняются. Пустая цена не разрешает подтверждение профиля.
При добавлении суммы цена сохраняется в подписанном расчёте и delivery_price;
INSURANCE получает только стоимость товарных позиций. Цена должна учитывать
согласованный воспроизводимый комплект материалов; автоматической покупки тары нет.

measurements_confirmed для automatic относится к исходным параметрам;
assembly_measured=false и weight_basis=calculated отделяют расчётный вес от
реального замера готовой посылки. Заказ хранит позиции для сборщика.

Черновики СДЭК не содержат вымышленных замеров. Учебные профили не допускаются в
рабочий checkout. Команда preview_auto_packing может явно использовать их и
запрашивать API без создания заказов/накладных. Исторические схемы не мигрируют
автоматически в новый режим и не получают подтверждений.
