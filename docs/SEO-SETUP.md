# Подключение поиска и план SEO

Решение владельца: индексировать `https://dari-sinergii.ru/` и библиотеку;
демомагазин пока исключить. Регистрация кабинетов сама по себе не включает
индексацию и не гарантирует позиции. Google и Яндекс могут находить сайт по ссылкам.

## Текущий статус

Разработчик сообщил о выполнении настройки и успешном подтверждении прав
в Яндекс Вебмастере и Google Search Console. Добавление sitemap выполнено
по его сообщению; внутренний статус обработки в кабинетах агент не просматривал.

Публично перепроверено: Google DNS и Cloudflare DNS через HTTPS отдают обе
TXT-записи подтверждения; `/sitemap.xml` отвечает HTTP 200 и содержит 11 URL,
включая `/materials/water-systems/`. TXT-записи следует сохранять после проверки.

Контроль обработки sitemap и индексирования пользователь 21 сентября отложил
со словами «проверим позже». При возвращении к этому этапу проверить обработку
sitemap, при необходимости отправить главную и страницу систем для воды на
переобход, затем смотреть индексирование и запросы.
Подтверждение владения завершено; включение страниц в поиск ещё не подтверждено.
Инструкции подключения ниже сохранены как памятка.

## Что подготовлено в коде

- `SITE_INDEXING_ENABLED=true`: основной сайт открыт поисковым роботам.
- `SHOP_INDEXING_ENABLED=false`: весь демомагазин получает `noindex` в HTML и
  `X-Robots-Tag`, sitemap пуст. Даже при ошибочном включении флага наличие
  опубликованных `DEMO-*` сохраняет запрет индексации.
- Роботам разрешено читать публичные страницы магазина, чтобы увидеть `noindex`.
  Не добавлять `Disallow: /` для удаления демокаталога из поиска.
- Карта основного сайта: https://dari-sinergii.ru/sitemap.xml.
- Личные страницы, заказы и админка не предназначены для поиска.
- Пагинация каталога имеет отдельный canonical; параметры рекламы в него не входят.

Политика индексации выпущена 18.09.2026 в релизе `readiness-20260918` и проверена
после установки SEO-обновления от 21 сентября. Поисковые кабинеты подключены
по сообщению разработчика; внешнее наличие DNS-подтверждений перепроверено.

## Google Search Console

1. Войти в Google-аккаунт клиента на https://search.google.com/search-console.
2. Добавить доменный ресурс `dari-sinergii.ru` — он охватывает поддомены и протоколы.
3. Скопировать выданную TXT-запись. В действующей DNS-зоне REG.RU добавить её
   для корня домена, сохранив A, MX, SPF, DKIM и DMARC. Точное значение выдаёт Google.
   В DNSadmin для действующих `ns5.hosting.reg.ru` / `ns6.hosting.reg.ru` поле
   «Имя» — `dari-sinergii.ru.` с точкой в конце. Не создавать отдельный поддомен
   для названия сервиса подтверждения; значение целиком помещается в TXT.
4. Подтвердить владение, не удалять TXT после подтверждения. Разработчика добавить
   отдельным пользователем с необходимыми правами.
5. В Sitemaps добавить `https://dari-sinergii.ru/sitemap.xml`. Карту демомагазина
   пока не отправлять.
6. Проверить URL главной и одной тематической страницы в инструменте проверки,
   выполнить проверку опубликованной страницы и запросить индексирование.
7. Проверить демокарточку: ожидается исключение по `noindex` после повторного обхода.
   Затем отслеживать «Индексирование страниц», запросы и Core Web Vitals.

[Подтверждение владения Google](https://support.google.com/webmasters/answer/9008080?hl=ru).

## Яндекс Вебмастер

1. В аккаунте клиента открыть https://webmaster.yandex.ru/.
2. Добавить `https://dari-sinergii.ru/`, выбрать подтверждение DNS TXT и перенести
   запись в действующую зону REG.RU. Если кабинет предлагает иной способ,
   использовать именно его инструкцию; не придумывать токен проверки.
3. Добавить `https://shop.dari-sinergii.ru/` отдельным сайтом для контроля запрета
   индексации. Подтвердить права по инструкции кабинета.
4. В основном сайте передать `/sitemap.xml`, проверить robots.txt, диагностику,
   главное зеркало и переобход главной / страниц библиотеки.
5. Заполнить регион и сведения об организации по реальным данным клиента.
   Не указывать физический офис или географию, которых у компании нет.
6. Передать разработчику отдельные права доступа. Метрика подключается отдельно,
   если клиенту нужна аналитика; в этом аудите счётчик не добавлялся.

[Подтверждение прав Яндекс](https://yandex.ru/support/webmaster/ru/service/rights).

## Следующая работа с содержанием

| Страница | Тематика для последующей проверки спроса | Что дополнить после согласования |
|---|---|---|
| `/` | бренд, системы озонирования воды | понятное описание услуги, производство, подтверждённые реквизиты |
| `/materials/water-systems/` | подбор и монтаж систем озонирования воды | реальные характеристики оборудования, фотографии и кейсы |
| `/materials/technology/` | технология озона и ограничения применения | проверенные источники и сведения по конкретной продукции |
| `/materials/oils/` | озонированные масла | назначение, состав, ограничения и проверенные документы |
| `/materials/hydrolats/` | гидролаты | описание продукции, применение по документации |
| отраслевые подборки | применение в соответствующей отрасли | реальные кейсы, условия, вопросы и ответы |

Это темы, а не исследованное семантическое ядро: частотность, регион, конкуренты
и приоритеты продаж ещё не известны. Значительная часть подробностей находится
в PDF; полезные ответы стоит добавить в HTML. Не превращать тексты про озон и уход
в неподтверждённые лечебные обещания. Авторство и источники согласовать с клиентом.

Структурированные данные Organization и BreadcrumbList добавлены и публично
проверены в SEO-релизе от 21 сентября; сведения компании берутся из CMS.
Product/Offer для вымышленного ассортимента не публиковать. Проверять результат
в Rich Results Test, без обещаний расширенного сниппета.

Для скорости нужны отдельные замеры PageSpeed Insights / полевые данные CrUX;
HTTP-время ответа и прохождение браузерных тестов не заменяют Core Web Vitals.

Методика аудита: [seo-audit на GitHub](https://github.com/coreyhaines31/marketingskills/blob/main/skills/seo-audit/SKILL.md).
В исходной подготовке скилл прочитан как чеклист. Для отдельного аудита от
21 сентября инструкции закреплённой версии загружены в изолированную папку
артефактов; сторонние исполняемые скрипты набора не запускались. Подробности:
[SEO-AUDIT-2026-09-21.md](SEO-AUDIT-2026-09-21.md).
