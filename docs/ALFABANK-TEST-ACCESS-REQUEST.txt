Кому: менеджеру по интернет-эквайрингу / технической поддержке интеграции Альфа-Банка
Тема: Тестовые доступы REST API для shop.dari-sinergii.ru

Здравствуйте!

Готовим к запуску интернет-магазин https://shop.dari-sinergii.ru.
Основной сайт https://dari-sinergii.ru — отдельный лендинг.
Магазин использует собственную интеграцию: заказ создаётся на сайте,
покупатель перенаправляется на платёжную страницу банка, после оплаты
сайт сверяет результат через банковский API.

Просим предоставить тестовые доступы для интеграции и уточнить:

1. API-логин и пароль для тестовых запросов, а также доступ в тестовый
   личный кабинет оператора для проверки платежей и возвратов.

2. Совместимость с нашим адаптером REST: register.do и getOrderStatusExtended.do
   (версия ответа 03 или новее, с суммами оплаты/возврата и merchant-параметрами).
   Сейчас в коде предусмотрены https://alfa.rbsuat.com/payment/rest/ для тестов
   и https://pay.alfabank.ru/payment/rest/ для рабочего режима.
   Подтвердите актуальные адреса API и платёжной страницы, тип выдаваемого логина.
   Если предполагается другой шлюз, пришлите его документацию: сначала проверим
   совместимость и при необходимости адаптируем интеграцию.

3. Актуальные тестовые карты и сценарии успешной оплаты, отказа, повторной
   попытки, полного и частичного возврата; настройку серверных уведомлений.
   Будущий рабочий callback:
   https://shop.dari-sinergii.ru/payments/alfabank/webhook/
   Адрес отдельного тестового стенда согласуем при его настройке.

4. Доступные варианты фискализации и порядок проверки тестовых чеков.
   Кассовый сервис пока не выбран; возможность передавать товарную корзину
   через orderBundle в коде предусмотрена.

Также просим уточнить порядок повторного рассмотрения магазина и требования
к безопасности: в предыдущей заявке были замечания, но точный текст отказа
у нас не сохранился. Готовность реальных оплат пока не заявляем.

Рабочие платежи сейчас выключены. Полученные секреты внесём непосредственно
в закрытые настройки сервера; в исходный код и общедоступные отчёты их не добавляем.

передайте запрос менеджеру по вашей заявке. При необходимости дополните ИНН
и номером заявки. Это подготовленный текст; автоматически он не отправлялся.
