## Почта REG.RU

| Поле | Значение |
|---|---|
| Название почтового продукта / ID услуги | |
| SMTP hostname / port / SSL или STARTTLS | |
| Логин SMTP | |
| Пароль SMTP / запись хранилища | |
| From: имя и адрес | |
| Адрес менеджера | |
| Reply-To: адрес для покупателей | |
| Адрес webmail / IMAP, если нужен | |
| Лимиты отправки / квота ящика | |
| DKIM selector и где включается подпись | |
| SPF / DKIM / DMARC: дата проверки письма, pass/fail | |
| Куда приходят возвраты недоставленных писем | |

Реальные адреса менеджера и Reply-To меняются через админку → «Почтовые
уведомления». SMTP-пароль хранится только в серверном окружении. Автоматических
рекламных рассылок и базы подписчиков в проекте нет.

## Все переменные проекта

Сверять с `.env.example` перед передачей. Ниже значения намеренно оставлены
пустыми; секреты заполнять только в приватной копии. Рабочее окружение загружается
systemd, файл `.env` в каталоге исходников автоматически не читается.
